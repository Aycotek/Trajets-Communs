Limites de cet essai

Aucun seuil n'est adopté : le plafond de minutes conducteur est un paramètre de simulation (Réglages). Les durées sont précalculées, sans trafic. Le tracé routier d'un groupe est demandé à OSRM (serveur public de démonstration) quand on le sélectionne. Les personnes sans groupe n'ont aucun trajet proposé et aucun repli n'est défini.

DÉMONSTRATION · données fictives · intégrations simulées

Aucun salarié réel, aucun domicile réel, aucune trace GPS réelle. Les profils portent des noms d'arbres. Le site d'arrivée, les gares et les centres de communes sont les seuls points réels. Les gains sont des estimations avec hypothèses visibles, pas des mesures. Aucune certification n'est revendiquée. Voir SOURCES.md et SECURITE.md.
